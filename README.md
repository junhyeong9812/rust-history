# Rust 변천사 아카이브

Rust의 역사를 **시대순 + 핵심 시스템 + 개념사**로 정리한 문서 모음이다. GC 없이 메모리 안전과 동시성을 어떻게 얻었고, 에디션으로 어떻게 진화하며, 무엇이 Rust를 "가장 사랑받는 언어"로 만들었는지를 다룬다. 모든 문서는 한국어. (자매: `java-history`·`database-history`·`python-history`)

## 읽는 법

01→06으로 읽으면 **"정체성을 깎아낸 역사"(1.0) → 호환 유지 진화(에디션) → 소유권이라는 핵심 → 동시성·생태계 → 그 바탕 개념**이 보인다. 03(소유권)·06(개념)이 Rust의 본질이고, corpus의 `불변성-값타입`·`에러-부재-표현`·`동시성-제어`와 직접 이어진다.

> 큰 줄기: **C++ 대체 목표 → GC·런타임 깎아냄 → 소유권으로 컴파일타임 안전 → fearless concurrency → 시스템·웹·도구로 확산.**
